# OpenWeather

An open-source weather app with 0 ads, 0 annoyances, and just plain information for the user.

Made for Hack Club's [Summer of Making](https://summer.hackclub.com/)

Made in Godot 4.4.1

## Setup:

To use this: go to https://lapis.codes/openweather and type in your city + zipcode and make sure that the location it tells you is near you, click yes, and then you can view the weather!
